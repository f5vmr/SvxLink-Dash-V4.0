Reflector node-map information
When enabled, the dashboard populates /etc/svxlink/node_info.json with public location and RF information for the connected reflector’s node map.

SvxLink LocationInfo and APRS
This is separate from reflector node-map publication. Enable it only when this installation should generate the SvxLink LocationInfo section and publish through APRS.

Public node and RF fields are available when either publication method is enabled. LocationInfo adds its own DMS, APRS, antenna and beacon requirements.
